# MLSpiral



a machine learning example using a reinforcement learning Long Short Term Memory neural network to search for the ideal hyper-parameters to use on a simpler supervised feed forward neural network



the feed forward neural network looks at a picture of coloured dots, where each colour roughly corresponds to a spiral, and tries to draw boundaries/fill in regions to sort them based off of colour. 



The Dots were generated by sampling a normal distribution to randomly place dots around K spirals, where each value of K corresponds to a different colour.



The FFNN used a gradient descent on a cross entropy loss function, 



The LSTM looks for the best combination of hyper-parameters sampled from the following sets:

learning rate: {0.1, 0.5, 1.0, 2.0}

activation function: {gaussian, RELU, Sigmoid, Softmax}

number of hidden layers: {2,3,4}

the number of nodes in each hidden layer is selected from the following

size of layers: {4, 8, 12, 16}



To compare the LSTM hyper-parameter results, a traditional grid search loop was also implemented 



The reinformcement for the neural network was defined by a custom reward function, which considered the accuracy of the model, the cost function of the model, the smoothness of the accuracy vs. epoch 



Each hyper-parameter set was used to train the FFNN on a subset of 70% of total generated points. The 



run initialize separately, then can run gridSearch.ipynb and NNSearchNNA.ipynb files to get either a grid search algorithm for optimal nn hyperparameters or a LTSM algorithm to try and find optimal nn hyperparameters
